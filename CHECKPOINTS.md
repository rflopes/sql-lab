# Checkpoints

A checkpoint takes at most 10 minutes, written by you in 3 or 4 lines. It never adds tasks: it only adjusts pace, order or difficulty. If a concept and a weekly checkpoint coincide, merge them into one.

## Concept checkpoint (end of each module)

- Explain the module's main idea in your own words, without looking anything up.
- Answer one prediction question ("what would happen if...?") and verify it in `pnpm sql`.
- What is still foggy? Pick one thing to revisit.
- Skim `GOTCHAS.md`.

### Template

```
## Module NN: <name>  (date)
Main idea:
Prediction + result:
Still foggy / to revisit:
```

## Weekly checkpoint (Friday)

- Sessions done vs planned (no judgment).
- Enjoyment, 1 to 5.
- Best moment of the week, however small.
- What got in the way.
- One adjustment for next week.

### Template

```
## Week N  (date)
Sessions: done / planned
Enjoyment (1-5):
Best moment:
What got in the way:
Adjustment for next week:
```
